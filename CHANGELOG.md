# Changelog

## [Unreleased]

- Optional add-ons are built from upstream sources and are no longer included in FlowMotion release assets.

## [0.1.0]

- First release.
- Diagrams and storyboards from YAML in `flowmotion` code blocks, rendered as animated SVG.
- Optional add-ons, off by default: a draw.io editor for `.drawio.flow` files and a Monaco code editor. Download the add-on zip from the release and turn the feature on in settings.
- Works without the add-ons: a plain text box stands in for the code editor, and draw.io files show a message with the download link.
